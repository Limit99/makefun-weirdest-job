# Apologising to the Printer

A tiny Node/TypeScript program for the make.fun bounty "Weirdest Job Title: Blind Judge Showdown". It writes one weird job title to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 60 characters.

Entry line:

> Senior Vice President of Apologising to the Printer

Run it with: `node main.ts`

Gate: one job title of 1 to 60 characters.
